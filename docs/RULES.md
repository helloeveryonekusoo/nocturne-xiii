# NOCTURNE XIII ルール仕様

通常は手札1枚で手番を迎えます。「1枚引く」または常時表示される「3枚見る」を選び、手札から1枚を使います。墓地は表向きです。

| 階位 | 名称 | 効果 |
|---:|---|---|
| 1 | 革命 | 墓地へ出た2枚目以降が公開処刑になる。13を選んでも対象は脱落しない。 |
| 2 | 捜査 | 対象の階位を宣言し、一致すれば脱落処理。 |
| 3 | 透視 | 対象の手札を使用者だけが見る。 |
| 4 | 静寂 | 次の実際の自分の手番まで効果を無効化。状態表示は一切しない。 |
| 5 | 疫病 | 対象に1枚引かせ、内容を見ずに一方を捨てる。 |
| 6 | 対面・対決 | 1枚目は互いに手札を見せ合うだけ。2枚目以降は小さい方が脱落し、同値なら続行。 |
| 7 | 選択 | 次の実際の手番で3枚から1枚を選べる。 |
| 8 | 交換 | 対象と手札を交換。 |
| 9 | 公開処刑 | 対象の2枚を公開して1枚を捨て、13の転生を封じる。 |
| 10 | 強制転生 | 10と残りの手札を捨て、新しい1枚を引く。 |
| 11 | 跳躍 | 次の生存プレイヤーの手番を飛ばす。 |
| 12 | 全体転生 | 自分以外を手番順に捨て札・補充処理。 |
| 13 | 潜伏・転生 | 使用不可。9以外で捨てられると未使用の転生札で復帰。手札に2枚揃った場合は両方を捨てて転生する。 |
| JOKER | ジョーカー | 数値は10。使用時に1～8・10～12から階位を宣言し、その効果を使う。1・6として使用しても、それぞれの使用回数には数えない。 |

## 7の記憶判定

- 「3枚見る」は権利の有無に関係なく同じ外観で毎手番表示します。
- 権利があるのに「1枚引く」を選ぶと、通常進行しつつ本人だけに約900ms「忘れてやーんの」を表示します。
- 権利がないのに「3枚見る」を選ぶと、3枚は表示せず1枚引き、手札からランダムに1枚を墓地へ置いて手番終了です。

## 勝敗

生存者が1人ならその人の勝利。全員脱落は引き分けです。山札切れでは生存者の手札を公開し、最大数値が勝利、同値は引き分けです。ジョーカーの数値は10として比較します。
